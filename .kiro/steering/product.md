# Product Summary

**Tiar Dwi Krisnanto — Professional Portfolio Website**

Website portfolio profesional untuk Tiar Dwi Krisnanto, IT Section Head / Senior Supervisor di PT Modernland Realty Tbk. Platform ini berfungsi sebagai representasi digital profesional yang ditujukan untuk rekruter, talent acquisition, dan pihak eksternal.

## Target Audience

- **Primary:** Rekruter IT / Tech — akses cepat via mobile/laptop (< 3 menit)
- **Secondary:** HR & Talent Acquisition — verifikasi background profesional
- **Admin:** Tiar sendiri — update konten tanpa bantuan developer

## Core Pages

1. **Hero / Landing** — Nama, jabatan, tagline, foto profil, CTA (download CV + kontak)
2. **About** — Narasi karir, highlight pencapaian, bilingual (ID/EN toggle)
3. **Experience** — Timeline visual pengalaman kerja
4. **Projects / Portfolio** — Card grid proyek dengan filter kategori (Security, Infrastructure, Development, Compliance)
5. **Certifications & Skills** — Sertifikasi, skill bars/tags, badges
6. **Contact** — Form kontak (Formspree/EmailJS), link sosial

## Key Features

- CMS-managed content (Sanity.io) — CRUD tanpa coding
- Bilingual support (ID & EN toggle)
- Animated counters for operational stats (social proof)
- Responsive: mobile, tablet, desktop (≥ 320px)
- SEO optimized, Lighthouse ≥ 90 all categories
- WCAG 2.1 Level AA accessibility

## Out of Scope (v1)

- Blog / artikel
- Dark mode
- E-commerce
- ATS integration
- Custom backend / REST API
